## [1.0.0] - 2025-01-09

### Added
- 🎉 Initial release of MedSecure ROI Calculator
- Interactive calculator with real-time calculations
- Real-world case studies:
  - Universal Health Services ($67M loss)
  - Scripps Health ($112.7M loss)
  - Hospital Clínic Barcelona (€5-8M loss)
  - Düsseldorf University Hospital (first ransomware death)
- Pre-configured scenarios:
  - Realistic (75% probability, 85% effectiveness)
  - Conservative (45% probability, 70% effectiveness)
  - Pessimistic (85% probability, 75% effectiveness)
- Comprehensive documentation in Spanish:
  - `justificacion-roi.md` - Complete ROI justification with sources
  - `defensa-roi-resumen.md` - Arguments for skeptics
  - `README.md` - Complete usage guide
- Key features:
  - Adjustable hospital parameters (beds, revenue, records)
  - Attack scenario customization
  - Investment cost estimation
  - Expected value calculations
  - Automatic ROI justification based on results
- Professional UI with gradient design
- Responsive layout for all devices
- Print-friendly reports
- Zero external dependencies
